# Qslice Examples

Code to reproduce illustrations and simulation studies from *Quantile Slice Sampling* 
by Matthew Heiner, Samuel Johnson, Joshua Christensen, and David Dahl. 

Some examples use the `qslice` R package available on CRAN: <https://cran.r-project.org/web/packages/qslice/index.html>.

Each of the `standard_targets`, `horseshoe`, `gprior`, `normalized_weights`, and `DLM_river` folders corresponds with 
a section of the paper and conatins a README file.
